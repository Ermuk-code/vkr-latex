\section*{ЗАКЛЮЧЕНИЕ}
\addcontentsline{toc}{section}{ЗАКЛЮЧЕНИЕ}

Разработанная серверная часть онлайн-площадки для сдачи вещей в аренду представляет собой полностью функциональный REST API, обеспечивающий работу всех ключевых бизнес-процессов платформы: регистрацию и верификацию пользователей, публикацию объявлений с системой премодерации, управление бронированиями и оплатой через Систему быстрых платежей.


В заключении можно выделить следующие основные результаты работы:

\begin{enumerate}
\item В ходе анализа предметной области были рассмотрены принципы функционирования онлайн-площадок для аренды вещей, изучены существующие решения. Были выявлены их достоинства и недостатки, определены ключевые функциональные требования к проектируемой системе и обоснована необходимость разработки серверной части с учётом специфики российского рынка.
\item Спроектирована база данных серверной части приложения. Выделены основные сущности: пользователи, объявления о сдаче вещей в аренду, бронирования с отслеживанием платёжного статуса и статуса залога, заявки на модерацию объявлений, отзывы. Установлены связи между сущностями, определены составные индексы для оптимизации запросов.
\item Разработан REST API веб-приложения. Реализован полный жизненный цикл бронирования: от создания заявки и её подтверждения владельцем до оплаты через Систему быстрых платежей, подтверждения передачи и возврата вещи с фотофиксацией, а также возврата залога. Реализована система модерации объявлений с сохранением снимков данных на момент подачи заявки. Для обеспечения безопасности применена JWT-аутентификация.
\item Выполнена интеграция с внешним сервисом DaData для автозаполнения реквизитов организаций и индивидуальных предпринимателей по номеру ИНН. Реализована валидация ИНН, КПП и ОГРНИП по алгоритму контрольных цифр, что исключает ввод некорректных юридических данных при регистрации пользователей.
\item Проведено тестирование разработанного API. Реализованы модульные тесты моделей, а также системные тесты сквозных сценариев с использованием APIClient.
\end{enumerate}

Все требования, объявленные в техническом задании, были полностью реализованы, все задачи, поставленные в начале разработки проекта, были также решены.

Разработанная серверная часть представляет собой готовое к развёртыванию решение и может быть использована как основа для создания коммерческой платформы аренды или масштабирована путём добавления новых категорий товаров и интеграции с реальными платёжными шлюзами.

Перспективой дальнейшего развития является интеграция с реальным провайдером СБП, интеграция с реальным криптопровайдером для ЭЦП, а также добавление курьерской доставки в веб-приложении.
